# Tableau des quarts

Outil de planification des quarts pour une traversée en voilier : répartition automatique équitable (heures, nuit, lever et coucher du soleil), équipage et durées paramétrables, modifications quart par quart, export agenda (.ics / .csv Google).

- Une seule page, sans serveur ni dépendance : `index.html`.
- Fonctionne hors ligne une fois la page ouverte ou enregistrée sur le téléphone.
- Les données restent dans le navigateur de chaque appareil (localStorage) ; la section Sauvegarde permet de transférer un planning d'un téléphone à l'autre.
